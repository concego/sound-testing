# Sound Testing

Página pública para testar, organizar e aprovar sons antes de integrá-los aos jogos.

## Organização das pastas

A página lê automaticamente os arquivos de áudio publicados nestas pastas:

- `sounds/01-efeitos-acoes/` → efeitos e ações
- `sounds/02-ambiente-cenario/` → ambiente e cenário
- `sounds/03-interface-feedback/` → interface e feedback
- `sounds/04-musica-outros/` → música e outros

As pastas estão vazias e prontas para receber os sons do próximo projeto.

## Como adicionar sons

1. No GitHub, abra o repositório e entre em **Add file → Upload files**.
2. Escolha a pasta correspondente.
3. Envie os arquivos e faça o commit.
4. Depois da publicação, a página carregará os sons automaticamente.

Também é possível testar arquivos temporários diretamente pelo painel. Esses arquivos ficam somente no navegador e não são enviados automaticamente ao repositório.

## Aprovação

A aprovação é marcada no navegador. A numeração exibida na página ajuda a referenciar os sons nos chats de desenvolvimento.

O botão **Copiar aprovados** gera uma lista pronta com as seções, a numeração e os nomes dos sons aprovados.
